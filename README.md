## 🌌 Tentang Proyek

Website ini adalah rumah digital bagi **XII MIPA 3 SMAN 1 Losarang**. Mengusung tema *Space Exploration*, website ini bukan sekadar profil kelas biasa, melainkan sebuah eksperimen dalam **AI-Driven Development**.

Seluruh struktur kode, mulai dari animasi roket preloader, sistem partikel Three.js, hingga logika "Stasiun Memori", dihasilkan melalui serangkaian *prompting* yang presisi kepada AI, tanpa penulisan kode manual (hand-coding).

## ✨ Fitur Utama

Berdasarkan *codebase* `index.html`, berikut adalah fitur unggulan website ini:

* **Interactive 3D Universe:** Menggunakan **Three.js** untuk merender ribuan partikel dan asteroid yang bereaksi terhadap pergerakan mouse.
* **Deep Space Atmosphere:**
    * Background 2D Stars dengan efek *twinkling* menggunakan HTML5 Canvas.
    * Efek *Shooting Stars* (Bintang jatuh) yang berjalan secara acak.
    * Efek *Nebula* menggunakan CSS Animations.
* **Glassmorphism UI:** Desain kartu transparan yang modern dan responsif.
* **Memory Station:** Fitur pesan bergilir otomatis yang memuat "Sinyal Kenangan" dari database array JavaScript.
* **Immersive Audio:** Dilengkapi dengan *autoplay* background music (M83 - Outro) untuk pengalaman emosional.
* **Rocket Preloader:** Animasi loading roket CSS yang halus sebelum masuk ke konten utama.

## 🛠️ Teknologi

Proyek ini dibangun menggunakan teknologi web standar tanpa framework berat, namun dengan integrasi library 3D:

* **Core:** HTML5, CSS3 (Advanced Animations & Variables), Vanilla JavaScript.
* **3D Engine:** [Three.js r128](https://threejs.org/) (via CDN).
* **Fonts:** Poppins (Google Fonts).
* **Development Method:** AI Prompt Engineering.

## 🤖 Bagaimana Ini Dibuat? (AI Workflow)

Proyek ini menantang metode coding tradisional. Alih-alih menulis sintaks, pengembang bertindak sebagai **Arsitek & Prompter**.

1.  **Konsep:** Meminta AI membuat tema "Luar Angkasa/Kosmik" dengan warna gelap dan neon.
2.  **Implementasi 3D:** Menginstruksikan AI untuk *generate* kode Three.js yang membuat partikel menyebar dan asteroid berputar.
3.  **Refinement:** Meminta AI memperbaiki responsivitas pada mobile (menonaktifkan Three.js berat di HP dan menggantinya dengan Canvas ringan).
